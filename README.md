# Дерьмометр

**Новый взгляд на ваше изображение.**

Личная визуальная лаборатория AoriOne. Анализируйте кадры, сравнивайте варианты и открывайте неожиданные детали.

### [Открыть приложение →](https://aorione.github.io/)

Перетащите изображение и начните исследование. Для отдельного окна и иконки в меню «Пуск» нажмите **«Установить»** в приложении, открытом через Edge или Chrome.

Изображения обрабатываются на вашем устройстве. Первичная подготовка инструментов выполняется одной кнопкой.
