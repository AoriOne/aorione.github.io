# Дерьмометр · AoriOne

Лаборатория изображений и персональный ИИ в одном пространстве. Анализируйте, редактируйте и создавайте — прямо на своём устройстве.

[Открыть приложение](https://aorione.github.io/)

- Анализ изображений, сравнение и история исследований.
- Полноэкранный ассистент с памятью диалогов, иллюстрациями и рабочими инструментами.
- Студия кода с редактором, экспортом и предпросмотром HTML.

При первом запуске нажмите **«Подготовить приложение»**. Комплект занимает менее 1 ГБ и сохраняется в браузере. Изображения и переписка обрабатываются локально.

Поддерживаются современные Chrome, Edge и Firefox. В Firefox приложение открывается как обычный сайт; установка отдельного приложения не требуется.

Здесь размещена готовая сборка. Исходный проект хранится в закрытом репозитории.
