# Дерьмометр

**Новый взгляд на ваше изображение.**

Личная визуальная лаборатория AoriOne. Анализируйте кадры, сравнивайте варианты и открывайте неожиданные детали.

### [Открыть приложение →](https://aorione.github.io/)

Перетащите изображение и начните исследование. Изображения обрабатываются на вашем устройстве. Первичная подготовка инструментов выполняется одной кнопкой.

Работает в актуальных Firefox, Chrome и Edge. В Firefox для Windows используйте значок веб-приложения в адресной строке: Firefox 143+, версия из Microsoft Store — 150+. На других системах Firefox доступен в обычной вкладке. В Chrome и Edge нажмите **«Установить»**.
